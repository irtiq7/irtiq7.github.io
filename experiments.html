Daily AI news dashboard

Open full screen →

A dashboard that pulls AI news from public RSS feeds (for example MIT News, TechCrunch, Wired, The Verge, and Machine Learning Mastery), groups the stories by source, and refreshes daily. It runs entirely in the browser.

  • Front end: plain JavaScript, with Plotly for charts.
  • Feeds are converted to JSON through the rss2json service, so the live view needs an internet connection and can be rate limited.

If the embedded view is blank, open the dashboard directly.
